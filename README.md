# DupFinder

写真・動画の **重複ファイルを探してゴミ箱へ移動する** ツールです。macOS / Windows 対応。

- **完全一致** — 名前やフォルダが違っても、内容が同じファイルを検出（動画・MTS も対応）
- **名前の重複** — `IMG (1).jpg` `IMG(2).jpg` `IMG のコピー.jpg` `IMG - コピー (2).jpg` `IMG copy.jpg` `IMG 2.jpg` など。元ファイルと同一内容か、内容が違うかを表示
- **RAW + JPG 同時記録** — ARW / CR2 / CR3 / NEF / RAF / ORF / RW2 / DNG … と JPG / HEIF のペアを検出し、どちらか一方をまとめて削除
- サムネイル表示、「開く」「Finder / エクスプローラーで表示」で確認しながら選べます
- 削除はすべて **ゴミ箱へ移動**（元に戻せます）。同一内容のファイルを全部消すことはできないようになっています

## ダウンロード

[Releases](../../releases/latest) から最新版をダウンロードしてください。

| OS | ファイル |
|---|---|
| macOS（Apple シリコン） | `DupFinder-x.y.z-mac.zip` |
| Windows 10 / 11 | `DupFinder-x.y.z-windows.zip` |

### macOS で初めて開くとき

署名していないアプリなので、初回は「開けません」と表示されます。

1. zip を展開し、`DupFinder.app` を「アプリケーション」フォルダへ移動
2. ダブルクリック →「完了」で閉じる
3. **システム設定 → プライバシーとセキュリティ** の下の方にある「DupFinder」の **このまま開く** を押す

（ターミナルが使える場合は `xattr -dr com.apple.quarantine /Applications/DupFinder.app` でも可）

### Windows で初めて開くとき

「Windows によって PC が保護されました」と出たら **詳細情報 → 実行** を押してください。

## 使い方

1. DupFinder を起動すると、ブラウザに操作画面が開きます
2. 「フォルダを選択…」で探したいフォルダを選び（複数可）、「スキャン開始」
3. タブごとに結果を確認。削除候補には自動でチェックが入ります
   - 完全一致：「(1)」付きや新しいファイルを削除候補に、1つは必ず残します
   - 名前の重複：元ファイルと **同一内容のものだけ** 自動選択
   - RAW + JPG：「すべての RAW を選択」/「すべての JPG を選択」でまとめて選択
4. 「ゴミ箱へ移動」

終わったら画面右上の「終了」を押してください（ブラウザを閉じても 3 分後に自動で終了します）。

### オプション

| オプション | 内容 |
|---|---|
| RAW と JPG が別フォルダでもペアにする | 同じファイル名で、更新時刻の差が 10 秒以内なら別フォルダでもペアとして扱う |
| 写真・動画のみ対象 | 書類などそれ以外のファイルを無視 |
| 動画の高速比較 | 64MB 以上のファイルは全体ではなく 32 か所をサンプリングして比較（速いが厳密ではない） |

### 検索しないもの

隠しファイル、`.photoslibrary`（写真ライブラリ）・Lightroom カタログ・`.app` などのパッケージの中身、ゴミ箱。
写真ライブラリの中のファイルを直接消すとライブラリが壊れるためです。

## ソースから実行

Python 3.8 以上があれば、外部ライブラリなしで動きます。

```bash
python3 dupfinder.py ~/Pictures
```

## ビルド

```bash
./build_mac.sh          # macOS → dist/DupFinder.app
```

```bat
build_windows.bat       :: Windows → dist\DupFinder.exe
```

`v*` タグを push すると GitHub Actions が mac / Windows 版をビルドしてリリースに添付します。
